# Signals, Stories, and Systems

This mini textbook introduces how persuasion, brand meaning, and visual design shape the way people understand products and experiences. It then connects those ideas to responsible AI-assisted creative and technical work.

4. [Chapter 4: The Plain White T-Shirt Case Study](04-white-tshirt-case-study.md)
5. [Chapter 5: Directing AI With Meaning and Judgment](05-synthesis.md)

## How to Use This Guide

Read the chapters in order, then return to the white T-shirt case study to see the first three ideas working together. As you read, pause at the questions and apply them to a product, organization, screen, or AI task you already know. Treat the guide as a set of lenses for noticing choices, not as a formula that replaces research or judgment.
